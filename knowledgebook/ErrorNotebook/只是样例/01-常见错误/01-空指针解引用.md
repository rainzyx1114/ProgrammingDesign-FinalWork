# 01-空指针解引用

## 错误代码

```cpp
int *p = nullptr;
*p = 10;  // 崩溃！
```

## 原因

未检查指针是否为空就直接使用。

## 解决

```cpp
if (p != nullptr) {
    *p = 10;
}
```

## 扩展

函数返回指针时尤其要注意：

```cpp
int *findValue(int key) {
    // 没找到返回 nullptr
    return nullptr;
}

// 调用方必须检查
int *result = findValue(42);
if (result != nullptr) {
    // 安全使用
}
```
