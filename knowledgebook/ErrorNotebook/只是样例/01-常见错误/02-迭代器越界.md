# 02-迭代器越界

## 错误代码

```cpp
vector<int> v = {1, 2, 3};
for (auto it = v.begin(); it != v.end(); ++it) {
    if (*it == 2) {
        v.erase(it);  // it 失效，++it 行为未定义！
    }
}
```

## 正确写法

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 2) {
        it = v.erase(it);  // 接住返回值
    } else {
        ++it;
    }
}
```

## 原因

erase 后迭代器失效，不能再对其 ++。
