# 02-内存管理

## 栈与堆

- 栈：自动分配释放，局部变量
- 堆：手动管理，`new` / `delete`

```cpp
int stackVar = 10;              // 栈
int *heapVar = new int(10);    // 堆
delete heapVar;                 // 必须释放
```

## RAII

资源获取即初始化，用对象的生命周期管理资源。

```cpp
class FileGuard {
    FILE *f;
public:
    FileGuard(const char *path) { f = fopen(path, "r"); }
    ~FileGuard() { if (f) fclose(f); }
};
```

## 智能指针

- `std::unique_ptr` — 独占所有权
- `std::shared_ptr` — 共享所有权，引用计数
- `std::weak_ptr` — 不增加计数，防止循环引用
