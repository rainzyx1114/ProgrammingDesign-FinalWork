# 指针与引用

## 指针

指针存储的是另一个变量的内存地址。

```cpp
int a = 10;
int *p = &a;   // p 指向 a
*p = 20;       // 通过指针修改 a 的值
```

- 指针可以为空：`int *p = nullptr;`
- 使用前检查：`if (p != nullptr) { ... }`

## 引用

引用是变量的别名，定义时必须初始化且不能修改指向。

```cpp
int a = 10;
int &ref = a;
ref = 20;      // a 也变成 20
```

#区别总结：

| | 指针 | 引用 |
|:---|:---|:---|
| 可为空 | 是 | 否 |
| 可修改指向 | 是 | 否 |
| 语法 | *p 解引用 | 直接使用 |
